第一課：先判斷你在哪一段

不要背二十多個 skill。先把工作定位成四類：想法、計畫、執行、特殊情況。

核心模型

  1. 想法還模糊：有 repo 用 /grill-with-docs，沒有 repo 用 /grill-me。
  2. 想法已清楚：多 session 工作依序用 /to-spec 和 /to-tickets。小工作直接 /implement。
  3. 開始執行：單票用 /implement，整份 spec 且可平行化用 /implement-spec。
  4. 特殊情況：bug 用 /diagnosing-bugs，超大型未知工作用 /wayfinder，需要 runnable answer 用 /prototype。
一句話規則：先問「我缺的是決策、計畫、程式碼，還是證據？」決策用 grilling，計畫用 spec/tickets，程式碼用 implement，證據用 prototype/research/diagnosis。

三個情境練習

  1. 你想新增會員等級，但規則、升降級與舊資料遷移都未定。答案：/grill-with-docs。
  2. 規格已確認，共八張相依 ticket，希望一次完成。答案：/implement-spec。
  3. 付款偶發重複扣款，目前沒有穩定重現方式。答案：/diagnosing-bugs。
